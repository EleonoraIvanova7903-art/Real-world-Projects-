# JavaScript String Methods – Practice Exercises

This folder contains structured practice exercises focused on core JavaScript string methods.

The exercises are designed to build a solid understanding of how string methods work in practical, real-world scenarios using basic HTML and JavaScript with DOM manipulation.

## Scope

The folder focuses on the following string methods:

- includes()
- indexOf()
- lastIndexOf()

These methods are practiced through small, isolated tasks to ensure clarity and correct mental models.

## Learning Objectives

By completing the exercises in this folder, you will learn how to:

- Check whether a string contains a specific word or character
- Detect the presence or absence of substrings
- Find the first occurrence of a substring
- Find the last occurrence of a substring
- Handle cases where a value is not found (-1)
- Apply string methods to user input via the DOM

## Project Structure

- Each task is stored in a separate HTML file
- Every file includes:
  - Minimal HTML structure
  - Input fields and buttons
  - JavaScript logic written inside a script tag
  - Results displayed directly in the page (no console usage)

File names follow a clear and consistent naming convention to reflect the task purpose.

## Target Audience

This folder is intended for:
- JavaScript beginners
- Learners strengthening fundamentals
- Practice before moving to more advanced validation logic

## Guidelines

- Focus on understanding the behavior of each method
- Test with multiple input values
- Avoid advanced JavaScript features unless explicitly intended
- Prioritize readability and logical clarity

## Notes

This is a learning-focused practice folder.
The emphasis is on correctness, predictability, and mastering fundamentals rather than optimization or advanced patterns.
